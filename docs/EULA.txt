2. DESCRIPTION OF THE APPLICATION
--------------------------------------------------------------------------------

Rescuer is a professional file recovery and data restoration suite designed
for the Microsoft Windows operating system (Windows 10 and Windows 11).
The Application provides, among other features:

  - A storage dashboard and drive manager that enumerate connected storage
    volumes and their health and capacity information;
  - A Recovery Wizard supporting several scan methodologies, including
    quick (filesystem metadata) scans, deep signature-based scans, partition
    scans, and Windows Recycle Bin scans;
  - Byte-for-byte disk imaging of storage devices (raw and forensic image
    formats), used to enable safe, offline recovery from captured images;
  - File preview and quality/confidence scoring to help assess recoverable
    candidates;
  - Generation of professional, shareable reports in HTML, PDF, and CSV
    formats;
  - Local settings management, including user-selectable themes and update
    preferences.

The Application is built using the Python programming language (Python 3.13
or newer), the Qt framework through PySide6, and The Sleuth Kit (TSK) via the
pytsk3 binding for low-level filesystem analysis. The Application stores its
user data (databases, configuration, logs, reports, and images) locally on
your computer.
